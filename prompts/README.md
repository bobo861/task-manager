## 第3轮：交互体验打磨

**我：** 提交后在浏览器验证，发现两个问题需要修复：
1. 刷新页面后数据丢失，进行中和完成状态的任务回到了待办列
2. 只能删除一个项目，第二次删除弹窗不再弹出

**Agent 修复：**
- **刷新数据丢失**：`handleSave` 和 `onDrop` 未调用 persist → 改用 `updateTask()` / `moveTask()`
- **第二次弹窗不显示**：确认后 `confirmVisible` 未重置 → 末尾补上 `confirmVisible.value = false`

**Agent 自主增强：**
- 创建 `ConfirmDialog.vue` 自定义确认弹窗
- 拖拽高亮反馈（列变蓝 + 阴影 + 放大）
- 卡片 TransitionGroup 入场/离场/移动动画
- 彩色计数徽标 + 空状态图标
- 按钮按压缩放、卡片悬停上浮

## 第5轮：最终打磨与细节完善

**我：** 最终验收发现三个问题需要修改：
1. 已完成的任务不应该能往回拖拽到待办或进行中，业务流程上做完就是做完了
2. 删除确认弹窗按 Esc 无法关闭，和新建任务弹窗行为不一致
3. 新建任务时标题是必填项，但点了创建没有任何反应，使用者不知道哪里有问题，应该给提示

**Agent 修复：**
- 已完成任务禁止拖拽（灰色半透明 + `onDragStart`/`onDrop` 双层拦截）
- ConfirmDialog 添加 Esc 键监听
- 标题为空时红色边框 + 错误提示「标题不能为空」，输入后自动清除

**Agent 自主补充：**
- 卡片底部显示创建时间 `MM-DD HH:mm`
- 自定义蓝色任务板 SVG favicon
- 移动端拖拽提示文字
